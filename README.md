# go-pkgx brand

Logos and icons for the [go-pkgx](https://github.com/go-pkgx) organization.

<img src="avatar/go-pkgx.png" width="160" alt="go-pkgx">

`logo.svg` is the source mark — a white isometric package on the amber
`#F59E0B → #B45309` gradient, a sibling of the go-* family marks. Amber is
go-pkgx's established identity.

## Formats

- **SVG** — `svg/color`, `svg/white` (white glyph, transparent), `svg/black`
  (black glyph, transparent)
- **PNG** 16→1024 px, 3 variants — `png/<variant>/<size>/`
- **JPG** (color, white background) — `jpg/<size>/`
- **ICO** (Windows favicon, multi-res 16→256) — `ico/go-pkgx.ico`
- **ICNS** (macOS) — `icns/go-pkgx.icns`
- **GitHub avatar** 512 px — `avatar/go-pkgx.png`
- **Social preview** 1280×640 (org profile / repo banner) — `social/go-pkgx.png`

The mark is theme-safe: a white glyph on the amber badge, never a white
background.
