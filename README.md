# go-pkgx brand

Logos and icons for the [go-pkgx](https://github.com/go-pkgx) organization.

`logo.svg` is the source mark — a white isometric package on the amber
`#F59E0B → #B45309` gradient, sibling of the go-* family marks. `social/` holds
rendered PNGs used by the org profile and repo banners.
